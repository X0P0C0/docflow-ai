# DocFlow AI 项目立项说明

## 项目名称

`DocFlow AI`

## 项目定位

这是一个面向内部协同场景的全栈项目，聚焦：

- 工单协同
- 知识沉淀
- AI 辅助工作台

## 为什么选择这个方向

- 像真实企业后台产品，而不是纯练手 demo
- 能覆盖 Java、数据库、权限、缓存、前后端分离等高频能力点
- 适合做成可持续迭代的长期项目
- 既能展示后端能力，也能展示前端产品化能力

## 核心价值

项目希望体现三类价值：

- 产品价值：有真实业务闭环
- 工程价值：有完整前后端结构
- 展示价值：适合演示、面试和继续扩展

## 最小版本目标

首个可用版本至少需要具备：

- 登录
- 工单列表 / 详情 / 创建
- 评论、指派、状态流转
- 知识文章列表 / 详情
- 从工单沉淀知识的路径

## 中期目标

- 知识创建 / 编辑 / 版本相关能力
- Dashboard 和 AI 工作台
- 角色与能力控制
- 通知、系统管理、个人中心

## 长期目标

- 更完整的权限模型
- 更清晰的工程化和部署体系
- 更真实的 AI 辅助行为
- 更稳定的测试与审计能力
