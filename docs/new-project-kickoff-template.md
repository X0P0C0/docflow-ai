# 新项目立项模板

## 1. 项目名称

示例：

- `DocFlow AI`

## 2. 一句话定位

示例：

- 面向内部协同的工单、知识和 AI 工作台系统

## 3. 为什么做

- 解决什么问题
- 面向谁使用
- 为什么值得长期维护

## 4. 最小可用版本

列出必须先跑通的最小闭环：

- 登录
- 核心列表
- 核心详情
- 核心写操作

## 5. 中期扩展方向

- 权限深化
- 统计概览
- AI 辅助
- 审计与通知

## 6. 技术栈

- 前端
- 后端
- 数据库
- 缓存
- 测试与部署

## 7. 风险与边界

- 当前不做什么
- 哪些能力后置
- 哪些依赖是高风险点

## 8. 成功标准

- 可运行
- 可演示
- 可交接
- 可继续维护
