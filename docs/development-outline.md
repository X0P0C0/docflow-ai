# DocFlow AI 开发大纲

## 文档目的

这份文档用于描述项目的开发主线，方便后续维护者快速理解“先做什么、后做什么、为什么这样做”。

## 主线一：基础可用

- 项目骨架搭建
- 数据库初始化
- 登录与鉴权基础
- 工单与知识接口最小可用

## 主线二：前后端联调

- 前端接入真实登录
- 前端接入工单列表 / 详情 / 创建
- 前端接入知识列表 / 详情
- 保留 demo fallback 保证联调连续性

## 主线三：前端后台化收敛

- 统一壳层和导航
- 重构工单页
- 重构知识页
- 收敛 Dashboard 和 AI Center
- 清理公共样式债务

## 主线四：质量收口

- 恢复关键单测
- 明确运行模式
- 补齐交付、交接和收尾文档

## 主线五：后续深化

- 数据库迁移机制
- 安全与默认配置收口
- 更完整的权限和审计
- 更强的 AI 工作台能力

## 当前所处位置

项目已完成前三条主线的大部分工作，并完成了质量收口中的文档与单测基线补齐。

当前更适合继续做“工程化深化”和“次级模块补强”，而不是重新做一轮大规模界面重构。
