# 前端 UI 设计方案

## 设计方向

当前项目的前端 UI 方向已经明确为：

`企业后台风格的管理工作台`

而不是：

- 营销页风格
- 概念稿风格
- 大面积 hero + 漂浮卡片的展示风格

## 设计目标

- 稳定
- 清楚
- 信息密度适中
- 便于继续扩展

## 页面层级原则

- 顶层是统一壳层
- 中层是列表、详情、表单三类后台页
- 底层才是卡片、标签、按钮和输入控件

## 视觉规则

### 颜色

- 以白、灰、蓝为主
- 状态色只表达状态，不做装饰

### 间距

- 紧凑但不拥挤
- 减少无意义大留白

### 卡片与边框

- 以轻边框和温和阴影为主
- 不追求强漂浮感

### 表单

- 输入框、选择器、按钮尽量统一尺寸
- 表单按后台结构组织，而不是海报式排布

## 当前结论

这份方案在本轮前端改造中已经基本落地到主流程页面：

- Dashboard
- 工单列表 / 详情 / 创建
- 知识列表 / 详情 / 编辑
- AI Center

## 后续建议

- 继续沉淀 spacing / typography / color token
- 继续清理剩余 view 级样式
